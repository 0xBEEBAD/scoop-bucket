# Scoop bucket for Arke

[Arke](https://github.com/Koimsurai/Arke) is a file explorer for Windows that never freezes.

```powershell
scoop bucket add arke https://github.com/Koimsurai/scoop-bucket
scoop install arke/arke
```

Update with `scoop update arke`. Arke notices it was installed by Scoop and leaves updating to it.

The manifest follows Arke's releases on its own: a daily workflow checks for a new version and updates the URLs and hashes.
